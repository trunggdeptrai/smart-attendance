# Smart Attendance – bản trình diễn

Bản demo của phần mềm hỗ trợ giáo viên điểm danh học sinh bằng nhận diện khuôn mặt.
Mã nguồn: kho GitHub `trunggdeptrai/smart-attendance` (tác giả: Phạm Hoàng Trung).

**Lưu ý:**
- Bản demo công khai, **chưa có đăng nhập**. Không tải lên ảnh khuôn mặt hay thông tin thật của học sinh.
- Dữ liệu lưu trên ổ đĩa tạm của Space và **bị xóa khi Space khởi động lại**.
- Camera trình duyệt cần cấp quyền; có thể dùng chế độ tải ảnh thay thế.
